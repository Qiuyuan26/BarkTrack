# Contributing

## Before you start

Read the project README, [overview](docs/project_overview.md), [architecture](docs/architecture.md), and [onboarding guide](docs/onboarding.md). The technology stack and map source are not finalized; propose significant choices as decision records before implementation.

## Working agreements

- Treat this as an independent student project, not an official NU service.
- Verify campus maps, room numbers, accessibility facilities, and routes with authorized sources before presenting them as accurate.
- Keep touchscreen use, accessibility, and clear directions in mind.
- Do not commit credentials, personal information, or restricted campus data.
- Document meaningful workflow, map-data, or design changes and state exactly what you verified.

## Pull requests

Describe the user need, change, verification performed, source of any campus data, and follow-up work. Link the related task or decision record where applicable.
