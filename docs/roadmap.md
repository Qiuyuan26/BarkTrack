# Roadmap

Provisional stages; sequence depends on requirements and available authorized campus information.

- [ ] Confirm initial kiosk location, audience, supported campus scope, and interaction requirements.
- [ ] Identify authorized map/directory sources, licensing, accuracy owner, and update cadence.
- [ ] Define destination schema, map layers, route graph, and accessibility metadata.
- [ ] Select interface, mapping, kiosk runtime, and any backend; record decisions.
- [ ] Build search, results, destination details, and map highlighting.
- [ ] Add route guidance only for verified walkable connections.
- [ ] Evaluate touchscreen usability, accessibility, stale-data behavior, and kiosk reset/privacy behavior.
- [ ] Confirm authorization and operational ownership before any real campus deployment.
