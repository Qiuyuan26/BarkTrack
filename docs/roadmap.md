# BarkTrack roadmap

## Prototype delivered

- [x] Landing page offers Find a Room and Navigate Between Buildings.
- [x] Indoor selection for NU Main, NU Mendiola, NU Annex 1, and NU Annex 2.
- [x] Searchable structured sample directory with campus-scoped filtering.
- [x] Interactive indoor schematic map with zoom, pan, reset, building selection, and floor controls.
- [x] Building and destination detail panels and clearly illustrative indoor route preview.
- [x] Outdoor origin/destination selection for NU Main, NU Mendiola, and NU Annex 2 (Mendiola), including swap.
- [x] Optional sample indoor destination selection and handoff to destination indoor guide.
- [x] Honest unavailable-route state; no unsupported outdoor distance, duration, streets, or turn-by-turn directions.
- [x] Responsive kiosk layout, empty states, and configurable idle reset.

## Before outdoor navigation can be enabled

- [ ] Obtain authorized, exact entrance points for each supported origin and destination.
- [ ] Select an approved outdoor mapping/routing service or maintain a verified pedestrian graph.
- [ ] Validate routes, distance/time estimates, street names, accessible paths, closures, and update cadence.
- [ ] Confirm data licensing and who owns route verification and updates.

## Before real indoor campus use

- [ ] Confirm authorized maps and directory sources for each campus and obtain permission.
- [ ] Validate building names, floors, room locations, entrances, and facility information with NU.
- [ ] Define a reviewed indoor route graph, accessible paths, closures, and multi-floor transitions.
- [ ] Test kiosk hardware, orientation, input, network/offline behavior, and timeout policy.
- [ ] Conduct accessibility and usability evaluation with representative visitors.
- [ ] Confirm operational ownership and authorization before any real campus deployment.

## Future expansion

- [ ] Add authenticated destination administration only if an approved workflow requires it.
- [ ] Consider persistent storage and a backend after update and deployment needs are known.
