# Project overview

## Purpose

BarkTrack is a student project concept for a touchscreen-friendly campus navigation kiosk. It is intended to help students, faculty, staff, and visitors find campus buildings, rooms, offices, laboratories, and facilities through search and visual directions.

## Intended users

- Students, including freshmen and transferees.
- Faculty and staff looking for rooms and services.
- Visitors and guests unfamiliar with campus.
- Maintainers who update verified destination and map information.

## Core workflow

1. A visitor searches by room, building, office, or facility.
2. The kiosk lists matching destinations with useful context such as building and floor.
3. The visitor selects a destination.
4. The map highlights the destination and shows a route when verified route data is available.
5. The kiosk returns to a clean start state after use or inactivity, according to the eventual interaction design.

## Principles

- Campus information and route guidance must come from authorized, verified sources.
- Distinguish unavailable or unverified information from confirmed destinations.
- Make touch interactions clear and support accessible route information where verified.
- Keep kiosk sessions free of unnecessary personal data.
- Do not imply official NU endorsement without authorization.

## Scope and status

The current repository is at the planning/scaffold stage. The README lists proposed features and technologies; implementation choices, map coverage, and deployment are not finalized.
