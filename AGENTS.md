# Contributor and agent guidance

- Read `README.md` and relevant files in `docs/` before making changes.
- BarkTrack is an independent student project concept, not an official NU system unless formally authorized.
- Proposed technology choices in the README are not final. Record framework, database, mapping library, or hosting decisions in `docs/decision/` before treating them as selected.
- Use only campus maps and destination information from authorized, verifiable sources. Mark mock or unverified map data clearly; do not publish it as accurate campus guidance.
- Design kiosk flows for touch input, clear wayfinding, accessibility, and a reliable return-to-home state.
- Update docs when changing workflows, architecture, data handling, destination information, or setup instructions.
- Prefer small, focused changes and explain assumptions in a relevant task or decision record.
