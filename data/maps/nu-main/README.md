# NU Main random sample floor plans

The prototype includes seven fictional floor maps from 1st through 7th Floor, with separate room arrangements and selectable sample destinations on each level. These plans are randomly designed for the UI demo. They are not based on NU Main's real architecture, room positions, entrances, or floor configuration.

Every map and room is visibly marked as sample. Do not use it for real navigation or copy it into official campus records. Replace it only with authorized, verified floor-plan geometry and matching room coordinates.
