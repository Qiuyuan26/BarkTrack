# Map assets

Store only map assets the project is authorized to use. Record source, license or permission, campus/building/floor coverage, date/version, and verification status. Do not present mock maps as navigationally accurate.

The interactive plans for NU Main, NU Annex 1, and NU Annex 2 are random samples, not official or measured floor plans. Each campus has a separate seven-floor room directory and a unique layout on every floor. See the campus-specific folders for details.
