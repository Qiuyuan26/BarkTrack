# Local preview

## Requirements

- Node.js 20.19+ or 22.12+
- npm

## Start the kiosk prototype

```powershell
cd frontend
npm install
npm run dev
```

Open the Vite local address in a browser. Use landscape orientation for the kiosk-style layout; the interface also adapts to tablet and desktop widths.

## Production preview

```powershell
npm run build
npm run preview
```

All map and directory records are fictional sample content. The prototype has no backend and should not be used to navigate real NU campuses.
